# 🌿 Ubon Ratchathani Travel Guide | แนะนำสถานที่ท่องเที่ยว จังหวัดอุบลราชธานี

ยินดีต้อนรับสู่ **จังหวัดอุบลราชธานี** เมืองใหญ่ริมฝั่งแม่น้ำโขง ดินแดนแห่งตะวันรุ่งก่อนใครในสยาม เต็มไปด้วยสถานที่ท่องเที่ยวทางธรรมชาติสุดอัศจรรย์และวัฒนธรรมท้องถิ่นที่ทรงเสน่ห์

---

## 📌 สถานที่ท่องเที่ยวแนะนำ (Highlights)

### ธรรมชาติและปรากฏการณ์อัศจรรย์
* **ผาแต้ม (อุทยานแห่งชาติผาแต้ม):** จุดชมพระอาทิตย์ขึ้นก่อนใครในประเทศไทย พร้อมชมภาพเขียนสีโบราณยุคก่อนประวัติศาสตร์ที่มีอายุมากกว่า 3,000 ปี
* **สามพันโบก:** แกรนด์แคนยอนเมืองไทย แอ่งหินกว้างใหญ่ใต้ลำน้ำโขงที่จะปรากฏให้เห็นความสวยงามเฉพาะช่วงน้ำลด (*ช่วงเวลาแนะนำ: พฤศจิกายน – พฤษภาคม*)
* **หาดชมดาว (แก่งชมดาว):** แนวหาดหินและแก่งหินกว้างใหญ่ริมแม่น้ำโขง มีริ้วลายหินและโบกรูปทรงแปลกตา เหมาะแก่การชมพระอาทิตย์ตกและถ่ายภาพธรรมชาติ
* **เกาะภูเก็ต (เกาะภูเก็ด อุบลฯ):** เกาะกลางแม่น้ำโขงในเขตอำเภอเขมราฐ แหล่งท่องเที่ยวทางธรรมชาติ Unseen ที่มีโขดหินสวยงามและทัศนียภาพลำน้ำโขงที่เงียบสงบ
* **น้ำตกแสงจันทร์ (น้ำตกรู):** ปรากฏการณ์ธรรมชาติสุดแปลกตาที่สายน้ำตกหล่นผ่านช่องรูหินปูนลงสู่เบื้องล่างอย่างงดงาม

---

## 🚗 การเดินทาง (Transportation)

* **เครื่องบิน:** บินตรงลงที่ *ท่าอากาศยานนานาชาติอุบลราชธานี (UBP)*
* **รถไฟ:** ขบวนรถไฟด่วน/ด่วนพิเศษ สายตะวันออกเฉียงเหนือ ลงที่ *สถานีอุบลราชธานี (อำเภอวารินชำราบ)*
* **รถประจำทาง:** มีรถโดยสารปรับอากาศเดินทางจากสถานีขนส่งหมอชิต 2 ลงสถานีขนส่งอุบลราชธานี
* **การเดินทางภายในจังหวัด:** แนะนำให้เช่ารถยนต์ขับขี่เอง เนื่องจากสถานที่ท่องเที่ยวทางธรรมชาติหลายแห่งอยู่ห่างจากอำเภอเมืองพอสมควร

- ช่วงเวลาที่เหมาะแก่การท่องเที่ยวธรรมชาติริมฝั่งโขง (สามพันโบก/หาดชมดาว/เกาะภูเก็ต): **พฤศจิกายน – พฤษภาคม** (ช่วงน้ำลดจะเห็นแก่งหินและโบกต่างๆ ได้ชัดเจนและสวยงามที่สุด)
